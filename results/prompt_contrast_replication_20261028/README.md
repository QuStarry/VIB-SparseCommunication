建议暂不替换核心默认。下一研究应将候选质量、合成提示和门控策略分开验证，使用更多未评测任务或新数据、固定模型身份与预定义成本预算，才能回答VIB本身是否在共同候选和等预算下提供增益；不继续针对本轮失败题补生成。
