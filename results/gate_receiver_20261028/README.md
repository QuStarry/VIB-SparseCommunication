# 共同候选门控接收端对照

从前两轮72题之外固定抽32题，共同历史Full六候选，四种接收策略各重复两次，共256次预声明请求。全部使用同一冻结规格优先提示，温度0、输出cap1024，串行single-attempt；生成全部结束后才载入隐藏测试，完整输出两次独立解释器检查。

## 人话结论

本轮真实数据支持“删去部分讨论仍得到相同的已观测通过结果”，不支持“VIB比朴素随机或余弦选择更准”。VIB比Full少接收63/192条消息（32.8125%）、少17.27%合成输入Token，历史代理合成费用少10.40%；不是整个多智能体端到端费用节省。

三个筛选组的输入消耗接近：VIB38316、随机38100、余弦38176 Token，实际输入并非相等。VIB没有对朴素对照显示特有质量收益；不要从同分推断公式最优，也不要把共同历史生成成本漏掉。

32题中24题出现不同原文输出，四组仍逐题通过状态相同，所以不是把一份缓存答案复制为四组。共同失败为HumanEval/127和132，两次生成全部失败：127把区间长度写成`end-start+1`，与公开题面示例的几何长度不符；132检测局部深度却未保证完整有效的嵌套子序列。筛选未在本轮纠正这些共同错误；没有按失败题补生成或修复。

## 预声明主比较

VIB减随机消息数匹配：-0.000pp；10000次任务级bootstrap95%区间[-0.000, -0.000]。
VIB更高0题，随机更高0题，平局32题；双侧精确方向检验p=1.000000。

主比较预声明alpha0.05；均值bootstrap与任务方向检验不是同一统计量，不能只挑有利结果。其他比较均探索性未校正；跨零不表示等效，没有非劣margin。

**特别提醒：本轮所有任务差值都为0，bootstrap只能反复重采样0，区间退化为[0,0]。它不是对总体差异的零不确定性证明。** `-0.000`是方向反转的浮点符号显示，数学上仍为0。不能写“精度完全无损”“通过等效性检验”或“总体绝对不会退化”。

以下为评分后补充的直观敏感性说明，非预注册新检验：若假设任务分歧事件独立同分布且服从二项模型，0/32分歧的单侧95%精确上界为`1-0.05**(1/32)=8.94%`。本实验实际是存档不放回抽样，不自动满足新任务总体的IID假设；这个数仅说明“样本零分歧”仍不等于“总体零风险”，也不是准确率差异或非劣上界。

## 编码与匹配协议

真实本地`all-MiniLM-L6-v2`，snapshot `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`，CPU/eval，384维，L2归一化。实际max_seq_length256，长消息按tokenizer截断；不是完整长代码语义表示。模型文件、库版本、向量与逐消息utility/阈值/历史均冻结在设计证据中。

VIB按现有主代码incremental历史逐条评估，保留代码差异、纠错关键词、代码角色beta、复杂度与adaptive代理等已有启发式；不是单独的信息瓶颈公式消融。无新增摘要、首轮最小角色数、隐藏反馈或自修复。

随机在每轮三条候选中不放回抽k，k精确等于该题该轮VIB通过数。余弦逐条贪心选择与已选历史最大相似度最小的k条，稳定按原消息顺序输出。这是数量匹配的条件对照；k来自冻结VIB决策，不是独立先验常数。不是原router的Bernoulli random或threshold topk配置，未改核心实现。

每题随机只固定一个task-salted选择种子，两次合成共享该子集；不是随机策略的多种子评估。角色数量未匹配，因此对随机的差异包含现有角色偏好与复合启发式，不能单独归因于信息瓶颈公式。

## 预算与因果边界

所有组每题两次调用、每次1024输出cap相同；随机和余弦逐题逐轮消息数量精确匹配VIB。消息长度、历史字节和输入Token不相等，因此不能称等实际费用对照。
本轮真实总计190505 Token，历史代理金额$0.0837906；截断0次，usage完整：True。
价格为2026-10-23输入$0.30/百万、输出$1.20/百万；$1为观察停机阈值，未取得实际美元/人民币invoice，不保证invoice硬上限。

只改变已有候选的接收历史。第二轮候选仍是历史Full生成，没有重生成删消息后Agent本应看到的上下文，因此不是完整协作闭环的VIB/Full因果证明。候选生成开销已经发生，不在本轮新增账单中，不能声称端到端成本节省。

来源仍是已审计HumanEval存档，不重叠于前两轮并不构成全新独立数据，不能排除预训练污染。模型ID匹配仅证明本轮返回声明，不证明官方immutable snapshot。

全量436项测试最终通过（181.05s）。本轮256个unique operation均为attempt1、finish_reason stop、known usage；完整输出共512次独立评分。真实缓存复用使用禁止客户端工厂，生成与分析复用、ledger SHA256不变、新API调用0；前两轮缓存仍可复用，未改变旧结果、核心路由、密钥或论文主表/PDF，未提交或推送。

下一研究应优先提高干预的可识别性：冻结新任务与候选、检查候选有无真实冲突，再比较完整反馈重生成或更严格预定义成本预算下的策略。候选质量检查不能使用隐藏答案来选择有利题目；本轮不据零差异继续调参数或挑种子。
