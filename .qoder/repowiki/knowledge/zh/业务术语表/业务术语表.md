### VIB-SparseComm
- 定义：项目全称「基于变分信息瓶颈的动态多智能体稀疏通信系统」的缩写，指代本研究所提出的核心机制：在时间维度上实现通信拓扑的动态自适应稀疏化，通过 VIB 理论评估候选消息的信息增益而非传统启发式过滤。
- 别名：VIB-SparseCommunication、VIB 稀疏通信

### VIB 路由器
- 定义：系统的核心门控组件，基于变分信息瓶颈理论计算候选消息的效用得分 Utility(M) = β_t · I(M;G) - I(M;H)，决定是否将消息广播到公共历史。包含任务充分性 I(M;G)、历史冗余度 I(M;H) 和动态衰减乘子 β_t 三个关键指标。
- 别名：VIBSparseCommRouter、VIB 门控路由器

### AgentState
- 定义：LangGraph 全局共享状态的 TypedDict 定义，包含 global_goal（全局目标）、history（已通过门控的公共对话历史）、candidates（待评估消息缓存）、step_t（协同轮次）等字段，是所有 Agent 可读写的统一状态结构。
- 别名：AgentState、全局状态

### 门控节点
- 定义：LangGraph 工作流中的 vib_gatekeeper 节点，负责运行 VIB 路由器对 candidates 缓冲区中的所有候选消息进行评估，将通过的消息追加至 history，并清空缓冲区推进 step_t。
- 别名：Gatekeeper、vib_gatekeeper

### 压缩率
- 定义：衡量稀疏通信效果的指标，计算公式为 (1 - approved/total) × 100%，表示被阻断的候选消息占总生成消息的比例。Milestone 2 验证中达到 75.0% 的压缩率。
- 别名：Compression Rate、剪枝率

### 上下文腐烂
- 定义：多智能体协作中因全连接通信导致的问题：冗余噪声累积使 AI 模型的注意力被稀释，影响后续推理质量。这是本系统要解决的核心痛点之一。
- 别名：Context Rot、上下文膨胀

### Milestone 1
- 定义：开发里程碑第一阶段，专注于 VIB 路由器的数学公式验证，通过构造高冗余和高价值两组极端案例，验证路由器能否给出符合直觉的 Utility 分数和拦截结果。
- 别名：M1、VIB 路由器单体测试

### Milestone 2
- 定义：开发里程碑第二阶段，搭建 LangGraph 基础状态机，不接真实大模型，用 Mock 数据跑通 Agent -> Buffer -> Gatekeeper -> Conditional Edge 的完整闭环拓扑。
- 别名：M2、LangGraph 状态机搭建
