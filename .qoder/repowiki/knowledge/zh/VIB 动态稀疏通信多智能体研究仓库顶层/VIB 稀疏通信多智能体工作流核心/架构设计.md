模块以 `__init__.py` 暴露顶层 API (`VIBSparseCommRouter`, `AgentState`, `VIBMultiAgentWorkflow`)，内部按职责拆分为四层、依赖单向：
- 编排层 `workflow.py`：基于 `langgraph.graph.StateGraph` 构建两节点有向图（`agents → vib_gatekeeper → {continue|end}`），通过 `AgentState` TypedDict 维护全局目标、公共历史、候选缓冲与轮次计数器；`run()` 使用 `app.stream()` 增量累积每步 gatekeeper 输出的已批准消息。
- 门控/路由层 `vib_router.py`：核心实现 VIB 目标 `β_t·I(M;G) - I(M;H)` 的数值近似，提供 `evaluate_detailed` 返回 `VIBEvaluationResult`；内含 Ada-VIB 自适应阈值（支持 token logprobs / confidence_score / 文本熵代理三种不确定度来源）、角色自适应 β（Architect/Coder/Reviewer 权重映射）、任务复杂度感知与 Code-Diff/Bugfix 信号修正。
- LLM 适配层 `llm_client.py` + `llm_agents.py`：`DeepSeekClient` 封装 OpenAI-compatible DeepSeek 调用并做单次重试与 token 用量统计；`LLMAgent` 将 role system prompt 与当前 history 拼装为 user message，输出符合 workflow 签名的 `generate(goal, history, step_t)` 函数。
- 状态定义 `state.py`：独立导出 `AgentState` TypedDict，供外部复用。
依赖方向单向：`workflow → vib_router → sentence-transformers`，`llm_agents → llm_client → openai`，二者均不反向引用编排层。
