本层为纯文档与统一入口层：`requirements.txt` 集中声明 numpy、sentence-transformers、langgraph、langchain-core、pytest、matplotlib 等跨子模块共享依赖；`docs/` 存放 VIB 理论论文草稿、LangGraph 实现参考与 PRD；三个 Python 脚本构成统一入口——`validate_milestone1.py` 验证 VIB Router 数学公式、`validate_milestone2.py` 驱动 LangGraph 状态机断言压缩率与阻塞计数、`run_summary.py` 串联两里程碑并输出汇总；所有脚本通过 `sys.path.insert(0, 'src')` 直接引入 `src/` 中的算法与状态机实现，而非 pip install -e 包结构，从而保持单包可直跑的实验形态。
