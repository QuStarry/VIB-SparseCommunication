- 每个实验脚本顶部声明 `#!/usr/bin/env python3` 并通过 `sys.path.insert(0, os.path.join(os.path.dirname(__file__), '..', 'src'))` 显式挂载上层实现，避免隐式包解析。
- API Key 统一通过 `os.environ.get('DEEPSEEK_API_KEY')` 读取，缺失时打印错误并 `sys.exit(1)`，不在代码中硬编码密钥。
- 实验结果以 `{prefix}_{YYYYMMDD_HHMMSS}.json` 命名写入 `results/` 子目录，便于后续 `glob` 按前缀匹配最新一次运行。
- 对比实验采用“对照组 + 实验组”双 Workflow 结构（如 HumanEval 中的 `BypassVIBRouter` vs `VIBSparseCommRouter`），在同一循环内顺序执行以便公平统计。
