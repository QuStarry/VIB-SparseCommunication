本模块为纯实验层（leaf），不依赖子包，所有可执行脚本均通过 `sys.path.insert(0, os.path.join(..., '..', 'src'))` 将上层 `src/` 中的实现（`vib_router`, `llm_client`, `llm_agents`, `workflow`）作为外部依赖导入，形成单向依赖：experiments → src。

按里程碑组织入口脚本：
- 数学/流程验证：`validate_milestone1.py`、`validate_milestone2.py`、`run_summary.py` 使用 mock agent 与轻量 embedding 模型验证路由公式与 LangGraph 状态机；
- 消融实验：`run_ablation.py` 对 β₀×λ 网格做笛卡尔积遍历，输出带时间戳的 JSON 到 `results/`，并计算 Pareto 前沿；
- 真实 LLM 评测：`run_comparison.py`、`run_e2e.py`、`run_humaneval.py`、`run_large_cluster.py` 基于 DeepSeekClient + VIBMultiAgentWorkflow 跑完整任务，其中 HumanEval 脚本内置 BypassVIBRouter 作为 Full Comm 对照基线；
- 结果汇总：`generate_report.py` 从 `results/` 中按前缀 glob 加载最新 milestone3/ablation 文件，打印中文总结报告。

数据产物集中在同级目录：`results/*.json` 保存结构化结果，`HumanEval.jsonl.gz` 由脚本首次运行时自动下载缓存，`logs.log` 记录运行日志。
