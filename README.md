# VIB-SparseCommunication
摘要与立论背景 (Abstract &amp; Motivation) 痛点：当前（2026年）多智能体协作常面临“推理长思维链膨胀”与“上下文注意力稀释”问题。全连接通信导致 API 开销及延迟呈二次方增长，且冗余噪声易引发“上下文腐烂”现象。  方法：本研究提出 VIB-SparseComm。我们抛弃了传统的启发式文本过滤，基于变分信息瓶颈（VIB）理论构建了轻量级信息增益评估器。  贡献：  建立了首个在多智能体交互中，以数学严格推导信息冗余与任务充分性权衡（Trade-off）的理论框架。  设计了时变衰减的动态拉格朗日门控，使系统在“前期充分发散、后期快速收敛”上达到最优。  在最主流的 LangGraph 上实现了该机制，在不降低任务表现的前提下，显著降低了通信 Token 开销。
